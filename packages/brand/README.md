# @meujogo/brand

Arquivos finais da marca usados pela interface: logo (`logo/`), padrões gráficos (`padroes/`) e emblemas de destaque em WebP (`emblemas/`).

São cópias. A fonte e os geradores ficam no hub da marca (`~/Documents/Clientes/MeuJogo/marca/`); quando um arquivo muda lá, ele é copiado de novo para cá. Nada aqui se edita à mão.

```ts
import simbolo from "@meujogo/brand/logo/meujogo-simbolo.svg?raw"
```
